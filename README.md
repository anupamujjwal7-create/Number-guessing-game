🕹️ How to Play
Run the script and you will be greeted with a welcome message.

Enter any whole number between 1 and 100 when prompted.

Use the clues ("Too high!" or "Too low!") to narrow down your next guess.

Win by guessing the correct number within 7 attempts!

When the game ends, type yes to play another round or no to exit.

🛠️ Customization
Feel free to open the code and tweak the variables at the top to change the difficulty:

lower_bound = 1 (Change the starting number)

upper_bound = 100 (Change the maximum number)

max_attempts = 7 (Give yourself more or fewer tries)
